Make the File Manager's file-list table sortable by clicking column headers.

- The table lives in the `filemanager-file-list` template block near the end of
  `web/templates/pages/filemanager.html`.
- Sortable columns: **File**, **Rows**, **Date Range**, **On**.
- Clicking a header sorts by that column; clicking the active header toggles
  ascending/descending. An indicator shows which column is active and in which
  direction.
- Sorting is **client-side**. Do not add `?sort=`/`?order=` query parameters or
  change any Go handler.

### The two constraints that make this non-trivial

**1. Typed comparison, not string comparison.** Each `<tr>` must carry
`data-` attributes holding raw comparable values — at minimum `data-name`,
`data-size` (bytes), `data-rows` (integer), `data-mindate` (ISO `YYYY-MM-DD`,
empty when the file has no parsed range), and `data-enabled` (`0`/`1`). Sort on
those, never on rendered text. The rendered cells show `25K` and `4K`, which
sort backwards as strings, and dates render in a range format that does not
sort lexically. Files with no date range must sort predictably (put them last
in ascending order) rather than landing arbitrarily.

**2. The sort must survive htmx swaps.** This table is the target of
`hx-target="#file-list" hx-swap="innerHTML"` from the enable/disable checkbox,
the per-row delete button, and the upload form. Every one of those replaces the
table markup and destroys any DOM ordering you applied. Persist the active sort
column and direction in page-level state and re-apply on `htmx:afterSettle`.
Verify by hand that toggling a file's "On" checkbox leaves the sort intact.

### Accessibility — non-negotiable, this is checked

`ACCESSIBILITY.md` in the swarm kit is the standard. Its "Project-specific"
section describes a different app, but the numbered baseline applies here:

- **A-4 / A-5 Keyboard.** The sort trigger must be a real `<button>` inside the
  `<th>`, reachable by Tab and operable by Enter and Space, with a visible focus
  indicator. A click handler on a bare `<th>` is a FAIL.
- **A-7 Real table semantics.** Keep `<th scope="col">`. Do not replace the
  table with divs.
- **A-9 Never color-only.** Sort state must be programmatically determinable:
  set `aria-sort="ascending"`/`"descending"` on the active `<th>` and remove it
  from the others. The arrow glyph is decorative — mark it `aria-hidden="true"`.
  An arrow alone, with no `aria-sort`, is a FAIL.
- **A-2 Both themes.** The indicator and focus ring must be visible in light
  and dark. The page ships both via Tailwind `dark:` classes.
