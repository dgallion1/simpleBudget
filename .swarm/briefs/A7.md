### Scope

A new page at `/transfers` in a new package `internal/handlers/transfers`,
plus its template. Three things:

1. **Monthly institution-flow chart** — how much moved between institutions
   per month. Follow the existing Plotly usage in `web/static/js/charts.js`.
   ACCESSIBILITY.md point 11 requires a text alternative: an adjacent data
   table carrying the same values (a disclosure is fine) plus a one-line text
   summary of the takeaway.
2. **Transfer history** — paired and external transfers, showing the two legs
   of a pair together and marking external legs as having no loaded
   counterparty.
3. **Suspected-pair review queue** — the pairs `SuspectedTransfers()` returns,
   each with confirm and reject actions posting via HTMX and calling
   `ResolveTransfer`. A confirmed pair becomes paired on the next load; a
   rejected one is never suggested again. Re-posting the same decision must be
   idempotent, not an error.
