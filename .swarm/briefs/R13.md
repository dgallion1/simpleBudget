# R13 — the resolve_transfer consent test asserts an echo, not the write (Tier 1, test-only)

Found by R10's checker while accepting R10. Not a code defect: `resolve_transfer`
writes correctly. It is a hole in the test that is supposed to prove it does.

## The gap

`TestResolveTransferApprovedInBrowserRecordsTheDescribedVerdict` asserts
`out.Verdict`. But `applyResolveTransfer` builds that field as an echo of its own
input (`internal/services/mcpsvc/ledger/resolve.go:234`):

```go
out := resolveTransferOutput{ Confirmed: true, PairKey: key, Verdict: string(v), ... }
```

So the assertion re-reads the argument the test passed in. R10's checker proved
the consequence by mutation: change the WRITE at `resolve.go:227` to persist the
OPPOSITE verdict while leaving the output field alone, and **all eight of R10's
tests still pass.**

That is precisely the risk R4 exists to eliminate — an approval displayed for one
operation authorizing another. R10 pinned the browser round trip and the refusal
path properly; this one assertion looks at the wrong thing.

The pre-existing `TestResolveTransferSecondCallWithTokenWrites`
(`resolve_test.go:75-103`) has the same assertion depth. It is in scope: the same
mutation should fail it too.

## Scope — TEST ONLY

Change no production code. `resolve_transfer` is correct; do not "fix" it. If you
conclude production code must change, STOP and report.

Work in `internal/services/mcpsvc/ledger/` only. Do NOT add files under
`internal/services/mcpsvc/confirm/` — a critical glob, and nothing here needs it.

1. The browser-approval test asserts the verdict actually PERSISTED to
   `transfer_decisions.json`, not the echoed output field. Read the file back and

2. `TestResolveTransferSecondCallWithTokenWrites` likewise asserts the persisted

4. R10's other seven tests still pass unchanged, including the refusal path's
   byte-comparison of `transfer_decisions.json`.

   the affected tests at least 20 times under `-race` and report the pass count.
   20/20 required — this repo has had enough flake investigations.
6. `go build ./... && go vet ./... && go test -race ./internal/services/mcpsvc/ledger/...`
   clean.

Write `.swarm/manifests/R13.1.files`. Report the mutation result, the 20-run
count, and each criterion with its evidence.
