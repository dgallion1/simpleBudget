### What to change in GLOSSARY.md

**1. Add definitions for the new vocabulary.** Every term below is used by
later tasks and must be defined precisely enough that a checker can hold code
against it:

- **Account** — a named source of transactions (id, name, institution, kind,
  file patterns, balance anchors). One CSV file maps to exactly one account,
  matched by filename pattern; first match wins, accounts sorted by ID. A file
  matching no account leaves `AccountID` empty ("unassigned") and is counted
  and surfaced in the UI, never silently dropped.
- **Account kind** — `checking` / `savings` / `brokerage` / `credit` / `other`.
  Note the one behavioral consequence: `credit` **forces** the credit-card sign
  convention for that file, overriding the ≥70%-positive heuristic.
- **Transfer** — the third `TransactionType`, alongside `Income` and `Outflow`.
  A transfer is neither income nor expense and is excluded from both, but
  unlike today it **remains visible** in the ledger and has its own page.
- **TransferClass** — `paired` (both legs present and linked) or `external`
  (a leg whose counterparty account is not loaded, e.g. Vanguard).
- **TransferPairKey** — the value shared by exactly two legs of one paired
  transfer.
- **StableID** — `accountID|YYYY-MM-DD|amount-in-cents|n`, where `n` is the
  occurrence index among rows identical in those first three fields, counted in
  file order. The amount is the **post-sign-normalization** value. Description
  is deliberately not part of the identity, so a bank reformatting its
  description text cannot orphan user decisions. Unassigned rows use
  `file:<basename>` in the accountID slot. Sidecar stores look up by StableID
  first and fall back to the legacy content `Hash`, rewriting to StableID on
  next save.
- **BalanceAnchor** — a user-entered `{date, amount}` stating an account's
  balance as of the **end** of that day. A balance is the latest anchor at or
  before a date plus the sum of that account's transactions after it. With no
  anchor, the balance is **unavailable** — not zero.
