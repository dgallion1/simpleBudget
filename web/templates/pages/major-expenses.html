How matching works
  • Keyword matches anything whose description contains it (case-insensitive).
  • Min = Max (e.g., 1580.00 / 1580.00) matches transactions of that exact amount — useful for fixed-amount checks. Works in addition to the keyword.
  • Min < Max with no keyword matches anything in that range. With a keyword, the range is used to flag anomalies instead.
  • Heads-up: amount-only matching can catch unrelated transactions of the same amount. Combine with a keyword when possible, or use a tighter range.
