# R2 — Folder import must not overwrite (Tier 2)

## The defect

`internal/handlers/explorer/handlers.go`, the folder-import path. Step 3
(around line 678) Stats the destination and returns "skipped" when it exists;
step 4 (line 685) then calls `deps.write`, an ordinary `WriteFile`. Between
those two operations a concurrent upload or import can create the destination
— and the write then overwrites it. Worse, step 6 deletes the source when
source-deletion is enabled, so the overwritten file is unrecoverable.

## The precedent (it is already in this same file)

The upload path at lines 911-913 does it correctly with
`store.CreateExclusive`, and its comment states the reason verbatim: a separate
Stat first would let two uploads of the same name both pass it and then
overwrite each other, and would read a permission or I/O error from Stat as
"absent" and overwrite anyway. Read that comment, then make the import path
obey it.

`Storage.CreateExclusive(path string, data []byte, perm os.FileMode) error`
already exists and is tested in
`internal/services/storage/create_exclusive_test.go`. Its signature is
identical to `importDeps.write`, so the seam is already the right shape.

## Scope

- The import write goes through `CreateExclusive`. `errors.Is(err, os.ErrExist)`
  maps to `importOutcome{Status: "skipped", Reason: "already exists in the data folder"}`.
- **A skipped import must not delete the source.** Confirm the control flow
  reaches step 6 only on a real import.
- Keep the readback verification (step 5) and keep rejecting a Stat error that
  is not `os.ErrNotExist`. The pre-check may stay as a fast path or go; the
  create is what decides.
- Nothing else in the import pipeline changes: symlink, non-regular-file,
  not-a-direct-child rejections and their exact reason strings stay as they are.

## Acceptance

- A test in which the destination is created between the existence check and
  the write: exactly one write wins, the loser reports `skipped`, the
  destination holds the winner's bytes, and **the loser's source file still
  exists on disk**.
- Existing import outcome tests (rejected / imported / skipped reasons) pass
  unchanged.
- `go build ./... && go vet ./... && go test -race ./...` clean.
