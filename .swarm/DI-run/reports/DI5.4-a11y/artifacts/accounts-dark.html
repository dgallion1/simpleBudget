Accounts Transfers File Manager

Accounts

Tell the app which CSV files belong to which account. A file is matched against each account’s patterns in ascending account-ID order; the first match wins. Files matching no account load as unassigned — they are still visible, but their rows carry no account attribution.

Add an account

Required fields are marked with an asterisk (*).

A stable slug, e.g. usaa-checking. Transactions and your saved decisions reference it, so it must be unique and should not be renamed casually.

credit forces the credit-card sign convention for this account’s files, overriding the ≥70%-positive heuristic. Other kinds leave the heuristic alone.

One pattern per line. Patterns are matched case-insensitively against the CSV filename: a glob first (path.Match), then a plain substring as a fallback. A pattern like usaa matches usaa-checking.csv.

Enter a dollar amount, e.g. 500. Leave blank or enter 0 to use the default of $500. Only meaningful for checking and savings accounts.
