# Z5.1 manifest — Spending-trajectory phase labels follow scenario-chain transitions

## Files changed

- `internal/models/whatif.go` — added `PhaseName string \`json:"phase_name,omitempty"\`` to `ProjectionYearSummary`.
- `internal/services/retirement/engine/stepper.go` — added `ProjectionState.CurrentPhaseName`; initialized in `NewProjectionState` via `s.GetSpendingPhaseNameAt(s.GetPhaseReferenceAge(0))`; recorded inside `StepMonth`'s `if m > 0` block via `st.CurrentPhaseName = s.GetSpendingPhaseNameAt(phaseAge)`, at the same site (same `s`, same `phaseAge`) as the existing `s.GetSpendingMultiplier(phaseAge)` call, so a chain transition earlier in the same `StepMonth` call is reflected in both together.
- `internal/services/retirement/engine/month.go` — `finalizeCurrentYear` now sets `currentYearSummary.PhaseName = st.CurrentPhaseName` before appending to `yearlySummaries`.
- `internal/handlers/whatif/spending_trajectory.go` — `buildSpendingTrajectoryRows` now builds a `phaseNameByYear` map from `projection.YearlySummaries[*].PhaseName` (only non-empty entries) and prefers it per row, falling back to `trajectoryPhaseName(s, yi)` when the summary has no name (no chain, or a projection built before this field existed; also preserves the disabled-phases "-" path).
- `internal/services/retirement/engine/engine_run_test.go` — added `TestEngineRunChainTransitionCarriesPhaseName`.
- `internal/handlers/whatif/spending_trajectory_test.go` — added `TestBuildSpendingTrajectoryRows_PrefersSummaryPhaseName` and `TestBuildSpendingTrajectoryRows_FallsBackWhenSummaryPhaseNameEmpty`.

## Tests added

Asserts `YearlySummaries[0].PhaseName == "Go-Go"` (primary, pre-transition) and `YearlySummaries[1]`/`[2].PhaseName == "Chain-Slow-Go"` (linked scenario, post-transition).
2. `TestBuildSpendingTrajectoryRows_PrefersSummaryPhaseName` (internal/handlers/whatif/spending_trajectory_test.go) — synthetic projection with `YearlySummaries[1].PhaseName = "Chain-Linked-Phase"`, which does NOT match what `trajectoryPhaseName(s, 1)` would compute from the primary settings ("Slow-Go"); asserts the row shows the summary's name.
3. `TestBuildSpendingTrajectoryRows_FallsBackWhenSummaryPhaseNameEmpty` (same file) — (a) no `YearlySummaries` at all: rows equal `trajectoryPhaseName(s, yi)` exactly (no chain, no behavior change on the common path); (b) phases disabled, with a summary row present carrying `PhaseName: ""`: row still shows "-".
