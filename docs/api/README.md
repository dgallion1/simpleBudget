| [`budget2/internal/handlers/insights`](internal/handlers/insights.md) | Package insights serves the Insights page and exposes pattern\-detection helpers \(income cadence, recurring expenses, anomaly detection\) used by both the dashboard and the what\-if defaults pipeline. |

| [`budget2/internal/models`](internal/models.md) | Package models defines the core domain types shared across the application: Transaction and TransactionSet \(the parsed CSV bank data\), dashboard KPIs, healthcare and major\-expense definitions, what\-if retirement settings and the WhatIfAnalysis result, persons/identities, and the insights pattern types. |
| [`budget2/internal/services/amazon`](internal/services/amazon.md) | Package amazon parses Amazon order\-history exports and matches them against bank transactions to produce enriched descriptions. |
| [`budget2/internal/services/backup`](internal/services/backup.md) | Package backup owns automatic and on\-demand snapshots of the data directory. |
| [`budget2/internal/services/classifier`](internal/services/classifier.md) | Package classifier infers transaction type \(Income vs Outflow vs Transfer\) from CSV row text using keyword and category dictionaries. |
| [`budget2/internal/services/dataloader`](internal/services/dataloader.md) | Package dataloader reads the user's bank\-export CSVs, normalizes per\-bank column layouts into a unified TransactionSet, applies user aliases, near\-duplicate decisions, Amazon enrichment, and major\-expense name overrides, and persists side files \(aliases, duplicate decisions, enrichment maps\) back to the encrypted\-at\-rest storage layer. |
| [`budget2/internal/services/majorexpenses`](internal/services/majorexpenses.md) | Package majorexpenses implements pure matching and exception detection over a TransactionSet given a list of user\-declared MajorExpense definitions. |
| [`budget2/internal/services/metrics`](internal/services/metrics.md) | Package metrics derives dashboard KPIs and trend sparklines from a TransactionSet — totals, savings rate, monthly buckets, and budget deltas. |

| [`budget2/internal/services/retirement/completeness`](internal/services/retirement/completeness.md) | Package completeness inspects a WhatIfSettings for silent zero\-defaults and other invariant violations that would produce mathematically valid but materially incomplete projections. |
| [`budget2/internal/services/retirement/engine`](internal/services/retirement/engine.md) | Package engine runs deterministic retirement projections from prepared settings. |
| [`budget2/internal/services/retirement/history`](internal/services/retirement/history.md) | Package history exposes historical market data used by backtest analyses. |
| [`budget2/internal/services/retirement`](internal/services/retirement.md) | Package retirement is the top\-level coordinator for what\-if retirement projections. |
| [`budget2/internal/services/retirement/prepare`](internal/services/retirement/prepare.md) | Package prepare turns a user\-facing WhatIfSettings configuration into a PreparedSettings witness that the retirement engine accepts. |

| [`budget2/internal/templates`](internal/templates.md) | Package templates loads the html/template files under web/templates, registers shared func\-map helpers \(currency, dates, JSON\-encoding for HTMX attribute payloads, etc.\), and exposes Renderer.Render |
| [`budget2/internal/testutil`](internal/testutil.md) | Package testutil provides testing utilities for the budget application. |
| [`budget2/internal/version`](internal/version.md) | Package version provides build information and version details. |
