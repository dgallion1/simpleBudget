posted `body: 'date=&amount='` — the handler's real form fields are
`anchor_date`/`anchor_amount`, so the wrong-named empty fields always hit
`handleAddAnchor`'s "required fields" validation branch (200, full

observed at the first run. Fixed by sending valid `anchor_date`/
`anchor_amount` values so the id lookup fails and the real `renderError`
404 path (`internal/handlers/accounts/handlers.go` ~line 312-315) runs.

5 failures (STATUS 200, 2x UNSTYLED per theme); after, `ERROR PROBE: clean`
for all three cases in both themes. No assertion in the probe was weakened
— only the test input was corrected to actually reach the code path the
